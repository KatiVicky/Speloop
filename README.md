# Speloop
【作品説明】  
Speloop（スぺループ）はローグライクとロックマンエグゼから着想を得たゲームです。  
就活用の作品として企画　プログラミング　アニメーション　イラスト　すべて作成しました。  
  
<img width="1536" height="863" alt="スクリーンショット 2026-01-26 110254" src="https://github.com/user-attachments/assets/cd57700d-0f5f-4426-a2fe-c9d1efc12f1e" />  
  
【ゲーム概要】  
Speloopはマス目で区切られたお互いの陣地から魔法を撃ち合うアクションゲームです。  
魔法には大まかな効果を決める「基礎魔法」と基礎魔法に付与する形で使用する「付与魔法」があります。  
付与魔法はHP・MPが続く限り何度でも、何種類でも重ね掛けできるので、戦況に合わせて組み合わせてオリジナルの魔法を唱えることができます。  
  
【工夫】  
敵AI  
敵AIには「思考速度」「行動速度」「攻撃優先度」などのパラメータを用意し、敵ごとに異なる性格や行動傾向を設定できるようにしました。  
また、AIの「思考」と「行動」を分離することで、常に複雑な判断処理を行うのではなく、必要なタイミングでのみ思考させる構造としています。これにより、処理負荷を抑えながら、プレイヤーから見て自然な行動を実現しました。  
  
ゲーム性  
「付与魔法を何度でも重ね掛けできる」というシステムを採用することで、個別の魔法を大量に実装することなく、多数の魔法の組み合わせを生み出せるようにしました。  
これにより、ゲームとしての戦略性を確保しながら、開発工数の削減にもつなげています。  

【改善点】  
現在は複数の処理が1つのクラスに集約されており、責務がやや肥大化しています。  
本来は機能ごとにクラスを分割することで、拡張性・保守性・可読性をさらに高められます。
